# TRITON X1 — 전단용 공개 페이지

전국 정비소에 뿌리는 전단에 주소를 인쇄하고, 그 주소로 들어온 사람에게
제품을 보여 주기 위한 한 장짜리 페이지입니다.

- **주소** : https://트리톤.kr (punycode `xn--oy2bi25bvxa.kr`)
- **파일** : `index.html` 하나. 사진은 전부 base64 로 박혀 있어 외부 요청이 없습니다.
- **호스팅** : GitHub Pages (무료). 도메인은 호스팅케이알에서 등록.

## 고치고 올리는 법

```bash
# 1. index.html 을 고친다
# 2. 올린다
git add -A && git commit -m "무엇을 고쳤는지" && git push
```

푸시하면 1~2 분 안에 https://트리톤.kr 에 반영됩니다.

GitHub 웹 화면에서 파일을 끌어다 놓아도 됩니다.
저장소 → `index.html` → 연필 아이콘 또는 Upload files.

## 이 페이지에 넣지 않는 것

전단을 받은 **아무나** 보는 페이지입니다. 다음은 절대 넣지 않습니다.

- 정비업체 전용가 (12,000원대) — 공개 페이지에 올라가면 전용가의 의미가 사라집니다
- 입금 계좌번호
- 회원가입 · 로그인 · 주문 · 관리자 기능
- 회원의 개인정보

주문과 회원 관리는 별도의 비공개 사이트에서 합니다
(저장소 `triton-x1-shop`, 비공개 유지. 그쪽은 과거 커밋 이력에 계좌번호와
관리자 비밀번호 해시가 남아 있어 **공개로 전환하면 안 됩니다**).

## 아직 정리되지 않은 것

전단은 전국에 나갑니다. 인쇄 전에 아래를 서류로 확인해야 합니다.

- **"PAO 기반 100% 합성"** — 제조사 MSDS 3항에는 고도 수소화 처리 광유가
  55% 초과, PAO 가 20% 초과로 신고돼 있습니다. 사실이라면 표시광고법상
  거짓·과장 광고가 됩니다.
- **OEM 승인 규격** — MB 229.51/229.52, BMW LONGLIFE-04, VW 504 00/507 00,
  PORSCHE C30/A40/C40, RENAULT RN17, OPEL OV 040 1547 D40, API SP.
  승인(approval)은 점도별로 따로 부여되므로 각 사 공개 승인 목록에 등재돼
  있는지 확인해야 합니다. 없는 승인을 표기하면 거짓광고 + 상표권 침해입니다.
- **"GERMAN QUALITY" 와 제조국** — 독일산이 아니면서 원산지 표시 없이
  독일을 연상시키는 표기만 두면 대외무역법 제33조 원산지 오인 표시에
  걸릴 수 있습니다. 제조국을 명시하거나 문구를 바꿔야 합니다.
